# Changelog

All notable changes to **Dev Health Reminder** will be documented in this file.

## [0.1.0] — 2026-02-23

### Added

- Three-tier break system: micro (20 min), medium (60 min), long (120 min)
- Configurable intervals via VS Code settings
- Three message tones: GenZ, Professional, Mixed
- Idle detection — timers pause after 5 minutes of inactivity
- Randomized exercise suggestions per break type
- 100% offline, zero telemetry, no external API calls
